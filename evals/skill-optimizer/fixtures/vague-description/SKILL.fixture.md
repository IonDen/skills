# Changelog helper

## Background

Changelogs are how users learn what changed between versions. A good
changelog saves users time and builds trust in a project, while a bad one
causes confusion and extra support requests. Many projects neglect their
changelog, and this skill exists to help with that.

## Steps

1. Read `CHANGELOG.md` and note its format.
2. Draft the new entry in the same format.
3. Do not edit released entries.

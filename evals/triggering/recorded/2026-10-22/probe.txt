## subagent types in the optimizer workspace
Here are the subagent types I can launch with the Agent tool:

- **claude**: Catch-all for tasks that don't fit a more specific agent. It has all tools.
- **code-explorer**: Explores codebases and reports findings. It has all tools.
- **Explore**: Read-only search agent for broad fan-out searches across many files, directories, or naming conventions. It locates code but doesn't review or audit it. It has all tools except Agent, Edit, Write, NotebookEdit, and a few others.
- **general-purpose**: Researches complex questions, searches for code, and runs multi-step tasks. It has all tools.
- **Plan**: Software architect agent that designs implementation plans, identifies critical files, and weighs trade-offs. It has the same read-only tool set as Explore.
- **plan-reviewer**: Reviews security-sensitive changes before merge, such as authentication, deserialization, or subprocess calls. It traces trust boundaries and drafts a remediation plan. It can only use Read, Grep, Glob, Agent(verifier), and ExitPlanMode.
- **statusline-setup**: Configures the user's Claude Code status line setting. It can only use Read and Edit.
